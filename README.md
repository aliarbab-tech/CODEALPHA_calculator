# 🧮 Ledger — Calculator

A basic calculator built with plain HTML, CSS and JavaScript, styled like a physical handheld device.

## Features

- All arithmetic operations: addition, subtraction, multiplication, division
- Chained operations (e.g. `5 + 3 × 2 =`)
- Clear (`AC`), sign toggle (`±`) and percentage (`%`)
- Real-time display updates
- Full keyboard support — numbers, `+ - * /`, `Enter`, `Backspace`, `Escape`
- Visual key-press feedback

## Tech stack

- HTML5
- CSS3 (Grid layout, transitions)
- Vanilla JavaScript (state management, keyboard event handling)

## How to run

1. Clone or download this repository.
2. Open `index.html` directly in any browser — no build step or server required.
3. Optional: use the **Live Server** VS Code extension for auto-reload while editing.

## File structure

```
├── index.html   # Calculator layout and buttons
├── style.css    # Theme, layout and key styling
└── script.js    # Calculation logic and keyboard support
```
